# 低秩 GRU：阶段成果、设计依据与后续迁移

记录日期：2026-10-23。用户明确要求保存本结果及设计经验，作为新架构与新缓存策略的参考。

## Material Passport

- 范围：本仓库 INT FM-only、自车真实历史帧、DAIR 同步流的工程实验。
- 证据：已完成的实际训练/完整验证及仓库代码；不是外部论文的原始指标。
- 状态：rank32 恢复训练完成 12 epoch，预算结束；同一最佳 e11 的整图/缓存指标均保留。未证明全局收敛或多种子显著优势。
- 主张：在已经压缩空间读出的 INT 成熟路径上，进一步低秩化 GRU 门卷积，恢复精度后减少卷积量和模型延迟。
- 边界：不是新逐格架构的结果，不是 SNN/脉冲节省，也不是 GRU 区域跳算结果。

## 1. 先说明到底比较了什么

研究中的“原 INT”指本仓库移植、在现有 DAIR 数据上训练的 ANN GRU FM-only 路径，不是论文原数据集排行榜。该原始参照 AP70=75.87361046%。

```text
原 INT FM-only GRU（成熟 ResNet、多尺度解码、空间读出、检测头）
  └─ 空间读出卷积 rank96 分解、精度恢复 → 紧凑整图基线
      └─ GRU 三门 rank32 分解、精度恢复 → 低秩 GRU 整图
          └─ 使用既有三帧深层锚点＋整图小修正 R → 低秩 GRU 缓存路径
```

直接受控比较是“紧凑基线”与“紧凑基线＋低秩 GRU”。两者使用相同成熟空间主干、解码/读出、检测头与 R；新增改变集中在 GRU 三个门。没有在完全未压缩读出的原 INT 上单独训练 rank32 后报告这张配对表，因此不能把所有累计收益都归于低秩 GRU。

原 INT 75.87361%、紧凑整图 75.62138%、低秩 GRU 整图 75.67024% 是不同组合的精度；低秩版比原 INT 低 0.20337 个百分点，比自身直接对照高 0.04886 个百分点。后一个小差异只解释为基本保持精度。

## 2. 具体结构：输入降维，输出接口和递归语义保持

每个门原来接收 128 通道：当前特征 x64 与对齐历史 h64 拼接。candidate 门使用 reset 调制后的历史，三门各有自己的投影权重，不共享投影。

```text
原门：        输入128 → 零填充 → 3×3卷积128→64 → BN → Sigmoid/Tanh
rank32门：    输入128 → 1×1投影128→32 → 零填充 → 3×3卷积32→64 → BN → Sigmoid/Tanh
```

投影无 bias；两层卷积之间不新增 BN 或激活，因此它是对原空间卷积沿输入通道维的低秩分解。投影放在零填充之前，得到与原网格一致的低维特征，可供后续选区研究。

初始化将原 W[64,128,3,3] 排成 [64×3×3,128]，做 SVD，取前 r=32 个奇异方向构成 1×1 投影及后续 3×3 权重。r=128 满秩路径用于边界、多帧及场景重置的等价核验。r=32 保留权重平方能量约 62.36%–70.98%，它仅是初始化权重近似量，不能当作检测精度或特征保真度。

保留的 GRU 更新是：

```text
r = sigmoid(BN(Kr(Pr([x, aligned_h]))))
z = sigmoid(BN(Kz(Pz([x, aligned_h]))))
n = tanh   (BN(Kn(Pn([x, r * aligned_h]))))
h_new = z * aligned_h + (1-z) * n
```

仍保存 64 通道 hidden 和 1 通道年龄，网格为 200×504；post_fusion、历史位姿对齐、真实时间差、场景切换/长间隔重置规则保持。完整 hidden 每帧照常更新，本实验没有通过脉冲或掩码跳过历史更新。

每门每个输出位置，原卷积需要 128×64×9=73,728 MACs；分解后为 128×32+32×64×9=22,528 MACs，门卷积本体减少约 69.44%。全 FM 仍包含 post_fusion 等，不能把这个百分比直接用于整网。

| 量 | 原 GRU | rank32 GRU |
| --- | ---: | ---: |
| 完整 FM 参数 | 259,712 | 106,112 |
| 本次参与恢复训练的参数 | — | 67,968 |
| 每帧 FM 标准卷积 GFLOPs | 52.25472 | 21.28896 |

## 3. 同轮配对结果：最应保留的成果表

固定恢复训练 e11，同一 GPU 逐帧轮换四种路径，DAIR 验证 5,794 扫描/1,738 标注帧。数据、检测后处理、权重检查点和评价口径一致。

| 同轮路径 | BEV AP70 | 标准卷积 GFLOPs | 平均模型 ms | P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 原紧凑整图 | 75.62138% | 252.13870 | 29.35700 | 30.49016 |
| rank32 整图 | 75.67024% | 221.17294 | 27.79337 | 28.85104 |
| 原紧凑＋三帧整图修正 | 75.53968% | 165.27618 | 18.88861 | 29.94346 |
| rank32＋三帧整图修正 | 75.55533% | 134.31042 | 17.26231 | 28.22907 |

缓存路径相对其直接对照：AP70 +0.01565 个百分点、标准卷积量减少 18.74%、平均模型延迟减少 8.61%。整图和缓存各少 30.96576 GFLOPs，因为 FM 每帧都运行。参数量下降是本设计的组成部分，不能标成同参数量的 GRU/SNN 对比。

“三帧整图修正”指固定深层锚点按三帧周期刷新，并受场景/时间间隔保护；普通帧运行现有 R，根据当前浅层特征和对齐锚点修正深层投影贡献。当前浅层支路与空间读出仍完整计算。它不是每三帧才更新 GRU，也不是只计算变化区域。

标准卷积 GFLOPs 采用实际执行的 Conv MACs×2；不是包含 warp、归一化、激活、数据搬运及所有线性算子的完整系统 FLOPs。模型时间包含模型内部缓存处理，但不含 IO/H2D/后处理；本次配对不能推广成所有硬件/负载下的固定加速比。

## 5. 可迁移经验：哪些已有证据，哪些仍是假设

| 设计经验 | 已有证据 | 对新架构/缓存的应用与限制 |
| --- | --- | --- |
| 优先减少昂贵空间操作的输入宽度 | 门卷积低秩化后，全网少30.97 GFLOPs，恢复后AP基本保持 | 已将固定e11 GRU接入新逐格架构；不再从未恢复的rank32起点训练。新U若再分解，须独立计入投影成本和恢复精度，不能直接套用rank32 |
| 保留成熟输出接口，局部替换后学习恢复 | hidden维度/递归/下游冻结仍可恢复 | 新H维度与后续成熟主干保持兼容；接口相同不保证精度相同，新结构仍要通过整图精度关 |
| 当前证据与历史缓存各有作用 | 低秩GRU保留当前输入；此前删除当前E明显掉点 | 每帧保留廉价当前观察，昂贵U只在选区运行；不能把静态假设变成完全不读当前输入 |
| 压缩、区域跳算、执行布局是三种不同收益 | 低秩压缩有实际收益；线性布局同算量减少延迟 | 分开对照后再组合，不能用更小网络的速度冒充缓存收益 |
| 选择值得缓存的单份状态，控制对齐/读写 | 三套高分辨率门缓存AP保持但内存4.24倍、延迟增加约60% | 新方向用较低分辨率的完整H，尽量共用对齐；不能因门缓存失败否定所有状态复用 |
| 局部执行依赖半径决定实际计算面积 | 直接拆成熟空间块导致halo计划过大、全部回退 | 将廉价邻域处理放在当前证据支路，昂贵逐格U不依赖邻格输出；仍须计入全图证据成本 |
| 必须用自己的近似状态闭环验证 | 门缓存闭环试验保持AP；单步核一致不替代闭环AP | 未选区保留对齐完整H，选区更新；刷新也由学生自身计算，不注入教师状态 |

不应迁移的结论：低维投影差异小不等于检测不重要；阈值导致低更新面积不保证精度；缓存响应与参考越多不一定越高效；ANN压缩成功不证明SNN独立价值。近期三门真实区域复用仅将整网卷积134.310→131.741 GFLOPs、时间17.282→27.640ms，作为负结果保留，不继续扩展三套门缓存。

## 6. 当前新架构及下一阶段实验顺序

当前网络已复用固定e11 GRU；新第一级为“继承成熟首块→廉价3×3/9×9深度卷积上下文→逐格513→512→512→128更新”，后续成熟空间主干/读出保持。首先以历史H/valid置零、全部位置更新训练完整基线。最新可确认 e6 AP70=74.09841%，低于e11参照75.67024%；第7轮运行中，基线尚未完成。

1. **整图精度关。** 继续完整恢复，观察AP、训练loss及平台降率；12轮预算不等于收敛。若仍有改善但预算结束，保留optimizer/scheduler/checkpoint后明确记录续训阶段；若充分降率后仍有差距，优先诊断空间上下文表达与冻结接口，不直接堆通道或启动低精度缓存。
2. **单份H状态学习。** 基线可用后，先让全部位置接收自己的对齐历史H及当前证据E，验证完整状态递归精度；教师只提供监督。再做未选位置完整复用H、选中位置执行U的训练，按新策略验证覆盖保护、状态年龄及场景重置。此处缓存完整H，不偷偷改成每帧密集更新状态、只缓存残差/门控。
3. **真实局部执行。** 同检查点比较全图U、同掩码全算后写回、真实选点U，区分策略误差和执行器误差。已有行主序线性执行与原布局在完整e5检测上AP一致、时间约少0.66ms，可作为候选执行器；布局收益单独列出。
4. **有界选区与刷新研究。** 先在训练片段核查当前证据与其同层对齐参考差异、未覆盖区域和缓存年龄；比较参考必须与被复用的H来源一致，避免每帧更新参考导致慢变化漏检。完整刷新周期及阈值在完整评价前登记；先保留明确刷新控制，再研究年龄触发，不预设静态区域比例。
5. **结论按整网口径。** 同时报告AP50/AP70、实际选中/实际计算面积（含halo）、全序列平均卷积/线性FLOPs、均值/P95和状态内存。面积/FLOPs减少是正向信号，但与GPU净延迟收益分别表述。

最新逐轮进展见[主研究记录](int_local_state_goal.md)。本成果作为固定参照保留，新架构成绩不覆盖此表。
