## 首版结构

每帧固定Pillar/scatter→低秩GRU32→成熟首个残差块，得到128通道E。普通帧不运行四层U、不计算H/D、不调用各尺度上采样、深层投影、成熟读出，也不持久保存H/D。持久空间状态仅完整Y256和位姿/时间；GRU的FM记忆明确保留，因此不是整个模型只有一份历史张量。

普通帧将Y按自车位姿对齐，把E128、旧Y256、覆盖标记1拼接，经1×1降到w通道→两层普通3×3→1×1输出256通道非负候选；同一隐藏特征产生逐位置门g=0.95sigmoid×valid，输出g×旧Y+(1-g)×候选。覆盖外g=0；初始gate bias4，接近复制旧Y。保留两层完整空间卷积，避免重走单层depthwise表达不足；旧Y参与候选计算，门上界只限制直接复制项，不宣称整体稳定性定理。

每3帧或距上次完整刷新0.25秒、场景/FM重置时，从当前E完整执行成熟H、深层两级、各尺度上采样/投影和读出，产生Y。刷新时H/D只是临时中间值，用后丢弃。检测头每帧完整运行。完整刷新间隔不额外拉长，先隔离“省掉H/D”这一结构变化。

第一阶段整图运行小更新器，尚不声称局部跳算。后续若精度可接受，用E与历史参考的差异及覆盖/自身置信保护形成选区，只执行候选网络及必要半径2邻域，未选位置直接复用对齐Y；增加参考和选区开销须重新记账。
