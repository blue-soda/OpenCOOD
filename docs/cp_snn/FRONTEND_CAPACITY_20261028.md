# 方案二前端容量与联合适配主对照

## 决策与假设

总目标仍是保留 SNN/IF 核心，在真实通信预算下接近 InfoCom/CoSDH 的 AP70。参数无硬上限。上一轮固定发送端的 BEV 扩容已完成四预算独立复核：2304B 大模型仅比匹配小模型高 0.06449 个百分点，低于预登记 0.5pp 门槛；4KiB 则为 58.180% 对 58.241%。结束 BEV 宽度搜索，不能据此断言全部误差一定来自编码器。

下一轮检验：增强发送前的三维上下文，并让完整 SNN 编码器适应低码率协作，能否提高固定字节下的任务信息质量。现有 fixed2k/multi 已训练 conv4、conv_out、消息投影/解码、接收器、BEV 和头；只说“解冻后段联合训练”不是新的实验。本轮两组都进一步训练 conv_input、conv1、conv2、conv3，候选单独增加 conv3/conv4 的稀疏脉冲残差深度。

## 两组匹配设计

| 项目 | F0 常规 SNN 前端 | F1 加深 SNN 前端 |
|---|---|---|
| 来源 | 同一 fixed2k 第6轮最佳权重 | 相同 |
| conv3/conv4 残差块数 | 各2块 | 各4块 |
| 联合训练 | 全部3D编码器、消息P/D、膜电位接收器、小ANN BEV、连续头 | 相同，另含新增块 |
| 消息接口 | 128通道3D输出→32通道IF8；实际2304B硬上限 | 相同 |
| 几何/接收/后端 | 现有对齐契约、接收器和小BEV | 相同 |

新增块采用现有 Count4→三维稀疏卷积→BN 的膜电位残差结构，作用于 stride4/8 的源坐标特征；不改占据坐标、通道语义、HeightCompression 或通信格式。两条残差支路最后 BN affine scale/bias 初始化为零，因此初始块是恒等映射；内部 BN scale 保留非零，随后支路可学习。所有 BN 运行统计固定，affine 参数可训练。新增权重构造隔离 RNG，避免改变两组后续采样与 dropout。

该改动是 SNN 前端容量实验，并非把加深网络本身称作协作机制创新。方案二的按 IF 发放顺序选择、实际字节截断与计数重建仍是通信机制核心；不恢复方案三。初始化时编码器指纹必然不同，不能要求完整包 SHA 相同；须核对解码计数与压缩负载、字节长度和预测一致，保留真实的不同指纹，不能冒用另一模型身份。

## 训练、选模和验收

- 同源 SHA `0add747f31daf1c34315621990ef1b9424e2606f2cb60fa23cc3f396bf9e6f9e`；各10轮，batch2，workers2，seed20260929，Adam 5e-5，7/9轮衰减0.1；Ldet(2304B)+0.5Ldet(0)，消息dropout0.1；CUDA matmul/cuDNN TF32均关闭。不同时追加蒸馏、量化范围或接收器改动。

- 启动门：四真实帧初始化预测/消息内容等价；各自 direct/wire 一致；零消息等于本车；真实batch2两步梯度与优化器覆盖；新增残差支路被激活、早期编码器梯度非零、冻结BN统计不变；审计更新丢弃。未通过不进入训练，不放宽门槛。
- 共享GPU须连续五次利用率≤20%、可用显存≥8000MiB；每组Torch分配上限25%。审计OOM或无梯度则记录失败并修复/重新排队，不擅改batch。每组训练上限96小时；每预算评估8小时；短TMPDIR，失败不自动重复。
- 主判断为F1−F0在2304B的AP70及各自协作−0B增益。较旧点提升混合了完整前端解冻和额外训练，不能单独归因于容量；F1−F0才是深度效应。实际均值/P95/最大字节必须同时报告，不能假设训练后包相同。
- 单次匹配十轮后，若F1−F0不足0.5pp，不继续深度/宽度扫描；若两组距InfoCom低率点62.87639%仍超过2pp，下一决策转向消息任务监督/检测表征，而非继续堆层。若有≥0.5pp收益，再做一次匹配种子复核。阶段目标仍是通信—AP，不以完成实验或更强参数量宣布达标。
