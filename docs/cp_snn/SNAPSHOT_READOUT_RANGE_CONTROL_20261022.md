# 消息固定的输出计数上限对照（2026-10-22）

## 目的与预登记

固定源64帧诊断发现同位置远端电流随预算显著变大，合成膜电位超过4的比例由约0.39%升至2.27%，但低端截断比例反而下降，绝对截断损失未单调增加。因此不能将完整消息AP下降直接解释为Count4上限饱和。

本轮只检验一个明确因素：**接收端输出计数上限4是否在当前固定系统中压低检测性能**。这是一项无需训练的反事实对照，不是新架构效果证明；不调增益、不添加归一化、阈值或损失。当前仅预登记，尚未实现或启动。

## 两种读出，其他内容相同

固定SNN P+D epoch4 best，SHA `c51a33f3c1d935a8528763ddbb68ccb3298475beab842a49c5a71216c56b5a78`。只在原本接收远端消息的空间支持位置替换最终Count4读出：

- 对照：`floor(clamp(U_local + I_remote, 0, 4) + 0.5)`。
- 干预：`floor(clamp_min(U_local + I_remote, 0) + 0.5)`，保留非负整数计数，取消输出4的上限。

没有远端支持的位置和零通信路径继续使用原Count4，保护已冻结本地路径。输入膜电位、D、门控、source-to-ego对齐、BEV和连续头均不变；不改变发送端0..8计数、安全上限或事件排序。此处取消的是**接收输出计数上限**，不是发送端每通道最多8次事件。

在2048bytes和完整消息两个预定操作点比较，两种读出共享每帧同一次源编码、同一真实序列化包、同一接收电流。两帧审计先检查原对照与已验证模型输出逐值一致、干预仅影响支持位置且符合显式公式、零通信不变；之后一次1738帧配对评估，两种读出各保存预测，逐帧bytes完全一致，独立CPU BEV/3D复算及GT/文件SHA检查。不得只替换AP而沿用另一运行的字节或预测。

## 解释与退出

若取消上限无收益或恶化，结束“上限截断是主要瓶颈”的本轮实用假设；不再搜索6/8/16上限、温度或增益。它不能否定所有可能的范围适配，因为冻结BEV原本见过有限计数，但不以此为理由自动追加训练。

若改善，仅支持输出范围值得纳入下一代任务脉冲表征/读出设计，还需预算内任务训练与强ANN对照；不能据此宣称SNN创新或能效优势。必须同时报告2048bytes和完整消息结果，避免只展示预算外的改善。

本阶段仅这两个操作点的一次配对对照，完成后回到任务相关发送/融合结构决策，不继续串行修补接收器参数。总目标仍是SNN风格协作的合格通信—AP。依据：[固定源电流诊断](SNAPSHOT_CHARGE_DIAGNOSTIC_20261022.md)、[已结束P+D适配](SNAPSHOT_TASK_ADAPT_20261021.md)。
