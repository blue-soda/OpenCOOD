# 低通信SNN候选的重复训练种子验证（2026-10-19）

## 目的与决策

总目标是SNN风格多车协作的合格通信量—AP，不要求特定三个机制联合实现。本轮只回答：已完成的Count3内容学习＋SNN Residual首包候选，在相同成熟初始化上改变适配训练随机性后，是否仍稳定超过固定单车参考，及其相对ANN的精度—字节权衡是否稳定？这不是从头训练编码器的多种子验证，也不是独立测试集验证。

首轮种子20260929：SNN首包59.52330%/4.57371kB，ANN首包61.07374%/6.94058kB。对应固定ANN/SNN单车57.98007%/54.77316%。本轮不再追加固定内容组，第一轮固定/学习对照保留为单种子机制证据。

## 启动前固定协议

- 四组：SNN/ANN学习内容，各训练种子20260930、20260931。结合原20260929公开全部三个适配种子，报告均值、样本标准差、最小值及每种子AP—字节，不只挑最高者。
- 从原`e3dsnn_content_round1_v2_20261019/{snn,ann}_learn/initial.pth`开始，逐字节验证；不是从该轮训练后的best继续。各家族源模型、P/D初始化、全部五个配置文件与首轮完全一致。
- 仍为各10轮、batch2、Adam5e-5、原里程碑和损失，仅融合与P/D训练，3D编码器、ANN BEV/连续头及BN冻结；不改通道数、体素比例、量化、后处理或数据。
- 首包是本轮主要稳健性观察点，但best选择仍是完整第三前缀AP70（含epoch0），避免改成更有利的选择协议。最终p1/p2/p3/off/full都验证，最终推理随机种子统一20260929。训练过程seed随组改变，训练内验证为同一固定数据、无随机增强。

## 判读与退出

三个SNN适配种子的首包AP70均超过两项固定单车参考，且真实平均通信维持当前低码率区间（预设不高于5.5kB/帧），才称当前固定源模型上的重复适配结果稳定达标；报告P95，不把该工程门槛称统计显著性。若有种子未达标，公开离散性并定位，不筛选种子。无论结果如何本轮结束，不追加同类搜索。

ANN使用相同额外训练预算和对应种子；其原空间保留比例与SNN不同，故这些点仍不是相同实际字节。完成后优先补强ANN的相近码率比较，并将可用候选转到车车/多车数据。SNN优势需由实际曲线及对照支持，不以低于FP32或少包头作为独立创新。
