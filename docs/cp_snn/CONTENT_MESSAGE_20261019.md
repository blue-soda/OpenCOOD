## 表示及空间/语义契约

冻结成熟3D编码器，在原始发送端坐标上取固定L1体素集合（沿用SNN25%/ANN50%，仅保持各自历史操作点，不称等码率）。新增无bias点式投影P：128→32通道，SNN输出Count3整数0..3；ANN控制使用相同宽度ReLU投影及逐帧逐通道2bit量化。接收端线性无bias展开D：32→128，再接成熟Residual融合、ANN BEV及连续检测头。32固定为本轮4:1通道瓶颈，不根据验证结果扫描宽度。压缩的是学习后的通道表示，真实总字节必须计入坐标/包头/尺度；不能把通道缩小4倍当作通信量缩小4倍。

对完整计数q，前缀k为min(q,k)，第k包事件为1[q≥k]，k=1,2,3；三包相加严格恢复q。ANN所有包共用整帧原始尺度，禁止逐包重新归一化。SNN值0..3可用两位精确表示，但相对原Count4特征是有损、可训练映射；不能称原特征无损压缩。展开矩阵可含负权重，产生接收端有符号电流；线上的计数仍非负。

每个包绑定源/目标帧、实际双方时间戳、发送者、共享3D编码器SHA、P和D及量化规则构成的basis SHA、32通道数、网格原点/步长/形状、整帧位姿和包序号。相同数值但不同basis不允许叠加。P学习混合原始通道，输出是统一约定的新潜在通道；不把潜在通道直接加到原128通道本地特征上。

每帧每发送者独立状态；先按原3D坐标对齐32通道事件，再在该basis下累积，保留三线性插值产生的连续小数，之后用D展开为接收端128通道。bias-free D与三线性插值满足线性交换关系，作为实现一致性检查；仍在HeightCompression之前对齐，禁止折叠高度后误配空间。融合在每个前缀使用原本地特征和累计远端特征重新读出，不能把上一前缀已经融合的输出再加一次累计消息。关闭路端应严格返回成熟源模型的本地路径。

这一版本使用成熟融合检验发送内容，避免把上一版新累计器的精度下降同时混入内容评价。SNN组保留已适配Count4 Residual融合，ANN组保留ANN Residual；ANN BEV和连续头冻结。原始本地膜电位保留在本帧上下文中，但不因每包重建而丢弃或把其他车辆膜电位直接相加。跨车学习P/D是显式通道变换，不能宣称天然语义一致。

## 有界对照与接入门槛

计划2家族×投影/展开冻结或学习，共4组；各家族一对共用源模型、固定的分组均值初始化P/D和逐值相同初始消息，均训练成熟融合，仅学习组更新P/D。新增P/D共8192权重。固定组用于判断收益是否确实来自学习内容，不能只用旧不同receiver作因果参照。ANN与SNN源权重不同，跨家族结果是系统比较。SNN源拟用message_fusion的snn_geometry，ANN源拟用budget_adapt的a_fusion；在实际接入时核对checkpoint SHA、配置和准确模块，不使用未核实路径启动。

冻结编码器、BEV/头、BN；计划额外10轮、seed20260929、batch2、Adam 5e-5、wd1e-4、milestones7/9；三前缀检测loss均值＋一次ego辅助loss，消息dropout0.1按帧，包含epoch0，统一按完整前缀AP70选best。每组6h上限，每次评估/复算1h，不自动重试。无重建loss/KD/额外排序器，不同时增加损失权重搜索。

正式训练前必须完成32通道codec（整包两位及三份二值事件包，实际报告重复坐标/尺度开销）、所有前缀直接/往返预测一致、包重复/错序/帧/位姿/basis/尺度拒收、不同样本不混合、增强batch2与逐样本一致、冻结摘要和梯度审计，四组初始化相等检查，以及全量零适配复核。0..3是新消息而不是把原Count4静默截断。未经这些门槛不启动训练。

最终同一best验证3前缀和关闭路端，报告1738帧BEV AP30/50/70、补充3D AP、逐帧实际bytes均值/P95、编码/解码和推理计时、冻结摘要、预测/GT哈希及CPU复算。保留旧Count4+SNN Residual59.54855%/16.00511kB、SNN+ANN Residual60.06059%/16.00511kB和强ANN61.14111%/15.53050kB。训练预算不同的历史点仅作实用参照，不作孤立机制因果结论。

四组结束即退出，不加宽度/位宽/比例/LR搜索。若学习组没有比本家族冻结组产生更好的实际AP—字节点，停止这个瓶颈；若产生候选，再登记稳健性与同码率控制，不立即宣布阶段一完成。阶段二叙事围绕可训练脉冲消息内容与严格对齐，须经结果和后续文献核验支持。
