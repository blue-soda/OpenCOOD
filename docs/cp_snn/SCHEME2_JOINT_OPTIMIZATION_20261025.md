# 方案二联合任务训练：固定预算与多预算主对照

2026-10-25 登记；用户要求与 CoSDH / InfoCom 复现并行推进，不再等待基线工程全部结束。总目标仍是 SNN 风格协作在 AP—实际通信—计算量中的可信优势；方案三继续暂停。

## 事实与假设

两种强 ANN 均有官方 DAIR 检查点，已完成共同 1738 帧、统一 GT 复评，无需从头训练才能建立原生基线。InfoCom 包含显式检查的 sigma/std 参数兼容映射，属于兼容复现。同通信预算的比较还需要给 ANN 低预算适配机会，不能把其原生高预算与我方低预算点直接宣布为胜负。

方案二源模型为 IF8 发放顺序、32 通道计数快照、三维对齐、解码、局部门控和 Count4 读出、ANN BEV 与连续检测头。源 SHA256 `c51a33f3c1d935a8528763ddbb68ccb3298475beab842a49c5a71216c56b5a78`；2 KiB 下 AP70 58.23401%，平均 2046.12 B；本地路径 57.46718%。先前 P/D-only 十轮收益仅 0.06884 个百分点，已经退出，不重复该局部搜索。

可证伪假设：冻结特征和检测后端限制了低预算脉冲的任务适配；扩大可训练范围后，多预算监督可能改善低预算 AP 及增加消息后的退化。此轮是方案二训练优化，并不把已有恒定驱动 IF 重新包装为新的网络机制。源完整消息 AP70 仅 51.19963%，不作为强教师做蒸馏。

## 两个匹配训练臂

| 项目 | fixed2k 对照 | multi248k 候选 |
|---|---|---|
| 初始化 | 同一已复核方案二 best | 相同 |
| 训练通信预算 | 2048 B | 每 batch 等概率 2048/4096/8192 B |
| 可训练部分 | 3D conv4/conv_out、128→32 投影、32→128 解码、局部门控/current_scale、ANN BEV、分类/回归/方向头 | 相同 |
| 冻结部分 | 早期 3D、所有 BN 统计、未使用的旧融合和评分器 | 相同 |
| 损失 | Ldet(B)+0.5 Ldet(0)，消息 dropout=0.1 | 相同 |
| 优化预算 | 10 epoch，batch=2，Adam 5e-5，7/9轮衰减，seed=20260929 | 相同 |
| 选模 | 每轮共同 2048 B 全验证 AP70，1–10轮 best | 相同 |
| 最终评估 | 同一 best 的 0/2048/4096/8192 B 全集 wire+CPU 复算 | 相同 |

早期编码器冻结不是永久架构约束。继承旧构造器后显式覆盖 requires_grad 和 train()，防止“写了联合训练、实际仍冻结后端”的接口错误。每轮核验全部非训练参数和 buffers 摘要。实际计费包含原有快照头、身份、坐标变换及载荷，不含网络帧头/重传；训练中的身份摘要仅用于包长选择，导出验证重新计算当前模型摘要。

旧 checkpoint 永久保留为独立锚点，本轮不延用旧优化器。为了尽快进入真实训练，不再做重复的 epoch0 全集扫描：启动审计逐位对比源模型在 0/2/4/8 KiB 的预测和字节数；新训练 best 仍可能低于旧锚点，届时明确报告回退。

## 启动门与退出标准

必须先通过：4678/1738 数据计数；源 SHA；同源推理逐位一致；四预算 direct/wire 一致及实际字节不超额；零消息等价本地；每个训练预算的真实检测梯度覆盖所有九个可训练组；冻结参数和 buffers 不变。审计更新丢弃，训练重新加载源权重。GPU 入场连续五次读数，至少 16 GiB 空闲、利用率不高于20%；每进程 Torch 分配上限60%，不终止其他用户任务。

一次固定十轮，不追加 LR、种子、阈值或轮数搜索。若两组相对原 2 KiB 锚点均无至少 0.5 AP 百分点增益，关闭这轮联合范围假设；该阈值是工程退出门，不是统计显著性。若有增益，先独立复核及匹配 ANN 预算曲线，再做种子与机制消融。通信更少但 AP 更低只称 Pareto 权衡；计算优势需相同 GPU、相同计时边界实测，不能用零值率或参数量代替。
