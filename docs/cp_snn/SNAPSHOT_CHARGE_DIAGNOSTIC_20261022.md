# 固定源消息的电流与读出范围诊断（2026-10-22）

## 目标与边界

P+D同追加预算的两组适配结束。2048bytes下SNN 58.23401%、ANN 59.40337%；两组各自相对epoch0的改善均不足0.1个百分点。关闭这轮局部优化，不继续增加轮数、学习率、位宽或解码层。当前尚未取得相对强量化ANN的通信—AP优势；允许SNN略低于ANN协作的总目标不等于已经证明SNN机制有效。

下一步应回到消息的任务语义与SNN融合结构。当前SNN把源端累计计数对齐后，经D和本地门控变成电流，直接加入本地连续膜电位，再用Count4读出：`Q=round(clamp(U_local+I_remote,0,4))`。更多脉冲会同时改变空间覆盖、通道内容和电流幅度。完整消息AP下降可以来自无关/错误内容、量纲不匹配、量化/截断或其他因素，不能仅凭下降就认定饱和。

## 一次只读诊断，先于任何新结构训练

固定已复核SNN epoch4 best（SHA `c51a33f3c1d935a8528763ddbb68ccb3298475beab842a49c5a71216c56b5a78`），使用验证集索引0至1737等距的64帧，索引由`linspace`预先生成，不按检测错误挑帧。每帧仅编码一次，在同一份本地膜电位和路端3D特征上比较2048、4096bytes与完整消息。真实编码/解码，保持原几何对齐、通道basis和完整计费；不改变任何权重、阈值、增益或检测输出。

记录源计数总量、非零通道数、远端电流RMS及符号、合成电位超过4/低于0的比例、相对本地新出现的越界、截断丢失幅度和输出计数改变。分别统计各预算自身支持位置、固定2048bytes支持位置、其中本地有特征的位置，避免把新增覆盖和同位置幅度变化混为一谈。`U>4`是高端截断，输出计数等于4还包含3.5至4的正常取整，二者必须分开。

每帧检查较大预算的源计数逐元素不小于较小预算；所有观测重算的读出必须与原始函数逐值一致。结束确认权重和全部缓冲不变。64帧统计仅为描述性定位，不计算新AP，不声称因果关系或部署能效。

实现：`opencood/tools/profile_e3dsnn_snapshot_charge.py`。本页登记时脚本已实现，尚待181启动并完成；没有新结构训练。

## 结果如何改变下一步

若同一空间支持位置随预算增加出现明显额外截断，将优先研究带明确电荷/时间标定的脉冲消息与读出，使不同长度消息的语义尺度稳定，而不是继续调任意融合增益。任何时间窗、尺度或阈值侧信息都必须传输计费，并以普通量化ANN同等标定为控制；具体架构和消融在看到诊断证据后另行登记。

若截断并未随预算恶化，不推进该解释；应优先检查发送端选择的任务相关性。即便看到截断增加，也只能支持进一步控制实验，不能证明它造成了AP损失。此次64帧诊断结束即退出，不无界扩展统计指标或再跑一遍完整AP。
