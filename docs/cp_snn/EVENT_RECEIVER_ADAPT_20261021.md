## 对齐、消息与审计

源网格、通道P和IF事件时序保持不变。累计源整数事件先按真实位姿做三维对齐，再由D映射到本地128通道、与本地膜电位结合及Count4读出。D不改变源地址/事件次序，门控与尺度也只作用于接收电流，禁止把不同语义直接累加。

协议摘要绑定P与D；适配D后会话版本随之改变，接收端必须使用对应配置。摘要仍完整计入通信，摘要定长且未压缩元数据，因此不会借接收器变化隐藏字节开销。真实batch审计在共享同一源编码的条件下验证优化前后发送事件数和字节完全相同；全量独立推理若有CUDA临界值差异，按实测逐帧记录，不强称跨运行逐值相同。

各组开训前检查direct/wire、零通信等于原ego、训练梯度只进入声明模块、一次丢弃的优化步后其他全部权重/缓冲不变。训练后再核对best及last所有未授权更新项逐值相同；发送P必须不变。所有组保留epoch0，不能用适配导致退化的最后一轮替代已登记best。
