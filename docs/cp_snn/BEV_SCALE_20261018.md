## 神经元改动与边界

只替换BEV主干及上采样前的14处Count4：

`y = s * floor(clamp(x / s, 0, 4) + 0.5)`，`s = exp(clamp(log_s, log(0.25), log(4)))`。

该步长同时联动发放阈值与输出幅度，不等同于只改变阈值。每处一个标量步长，共增加14个可学习参数（fixed对照为14个常量buffer）。使用原Count4的区间内替代梯度；log_s通过上述计算图求导，不引入新的连续旁路或ANN模块。s=1时前向及输入替代梯度与原Count4完全相同。BEV外的编码器与融合Count4不变，发送消息仍是原始整数Count4。
内部计数始终0—4，但接收端张量为缩放后的五级计数，不能说它仍是原始0—4整数。输出标量增益数学上可折入紧随其后的Conv2d/ConvTranspose2d权重，已做数值测试；当前实现仍用浮点除法/乘法与原CUDA卷积，尚未实现部署折叠或实测硬件AC/能耗收益。
本改动是第一阶段的接收端校准实验，不声明新颖性，也不是已证实的瓶颈机制。

## 验证与成功标准

1. 前轮完整复核状态、初始化SHA和发送端状态一致性必须通过。四组共享同一个扩展初始化checkpoint，只允许增加14个零log_s，拒绝其他缺失/未知参数。
2. 真实增强batch2核对四组初始检测输出与原模型精确相等、消息往返与直接特征一致；一次优化步验证编码器及BN不变、接收端有限非零梯度、learned的scale梯度有限非零且更新、fixed保持1。审计更新丢弃。
3. 四组全量零适配/3D/逐帧消息/CPU复算，全部相对来源AP30/50/70差值≤0.02个百分点后才训练。每轮记录14个scale、范围/边界命中、冻结哈希；非有限或越界状态报错。
4. 按AP70选择训练中的best，完整开/关路端评估、CPU复算、消息与GT诊断。保留未训练来源作为额外参照，不能因训练best变差覆盖原最佳。
5. 主要比较learned−fixed在各学习率下的差值；单独报告low−high，所有4组完整汇报。若只是low改善而learned不改善，采用学习率解释，不认定步长有效。
6. 进入下一轮重复的实用筛选条件：learned超过同LR fixed至少0.3个百分点且超过既有全SNN58.01125%，同时通信保持原发送端水平。0.3是预先选择的工程筛选阈值，不是统计显著性界限。未达到则保留原模型，并转向BEV分段/读出或监督定位，不反复挑种子或调阈值。
7. 通过后仍需匹配多种子和独立泛化验证；阶段总目标继续是全SNN协同AP70稳定超过ANN/SNN单车，并报告对ANN多车的精度差与通信，后续补等码率ANN对照。
