## 接入与有界顺序

1. **先做同内容codec审计，不改变内容。** 采用空间坐标、32位非零通道掩码、非零整数值和压缩的共同格式原则。ANN保持其0..3码值和32个原始FP32通道尺度；尺度必须随包传输并计费，不能在接收端免费读取发送端对象。SNN保留0..8计数及单位尺度约定；值位宽允许按已声明值域分别为2/4bit，不强迫ANN浪费两位。量化规则、编码器/P/D basis、帧/时间戳、网格及位姿必须纳入协议和校验，不冒用原IF身份来传ANN码值。
2. **先验证满消息语义。** 两帧真实点云中，与原ANN完整计数/固定尺度共享同一次编码，验证新传输重建的码值、尺度、对齐状态和检测输出。保留原三个二值层的对齐/累计读出顺序，避免把浮点求和次序变化混作codec错误。严格检查全空、错尺度/位姿/basis、截断和损坏包。没有完成满消息预测等价前，不运行预算AP。
3. **64帧成本与预算审计。** 使用一次固定的原L1空间优先级，不扫描排序器/量化位数/覆盖比例。ANN各位置内容仍为完整原2bit码值，按真实包长首次超额即停。统一预登记2048bytes上限，包括尺度及完整元数据。SNN单位IF前缀以相同新协议重新测量准入和字节，不能把旧协议的2048bytes点当作逐帧同协议控制。检查两家族空消息率、实际bytes/剩余预算、选择/编解码时间；报告选择粒度不同。
4. **两帧审计后一次全量。** 冻结模型，不增加训练。先各自完整快照，再各自2048bytes，共四个推理点；保存真实包/预测、逐帧通信量、配置/模型/GT摘要并独立CPU复算BEV/3D AP。完整快照用于区分协议成本与预算丢弃，不按验证AP调阈值。

## 公平性边界和退出

这是**强ANN的工程参照**：历史训练步数、接收器及选择粒度不同，不能称“仅SNN/ANN激活不同”的匹配因果消融。即使SNN胜出，也只说明这两个固定系统在该操作点的结果；若ANN表现差，不能因此宣布SNN特有优势或停止更强ANN预算适配。后续是否开展两家族同起点、同预算采样及同训练步数对照，由这一次实际结果决定。

四个推理点结束即退出本小阶段；不因接近某个AP反复调codec、L1比例、量化位宽或更多排序器。若协议压缩已解释主要通信收益，论文须如实归因；真正架构叙事仍需要任务脉冲表征、融合机制以及匹配ANN控制的证据。当前不以追加训练代替这一步成本与公平性核查。
