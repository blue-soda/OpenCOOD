# 发送端效用可预测性与严格字节准入（2026-10-22）

## 目的和预登记

上一轮16帧标签oracle降低损失，但不满足真实2KB预算，也不具备可部署的源端决策。下一步只检验一个问题：**从发送端自身特征学习脉冲效用符号，能否在未用于拟合的训练帧上、严格2048bytes内降低检测损失？** 不以oracle损失替代AP，不扩展接收器增益或计数上限。

本项是发送端可学习性的有界线性探针，尚非最终架构或SNN创新主张。相比旧体素评分，这次目标直接来自检测任务的脉冲效用，粒度是通道单位事件；但额外监督本身也适用于ANN，必须保留这一限制。

## 固定设置

- 146已有同源SNN P+D best，SHA `c51a33f3c1d935a8528763ddbb68ccb3298475beab842a49c5a71216c56b5a78`。全部检测器权重/BN冻结，Count4不变，关闭数据增强，seed20260929。
- 训练集索引等距选128帧，按顺序前96帧拟合、后32帧留出；验证集完全不读取，留出标签不进入拟合/归一化/学生决策。按帧切分，不能把同帧不同通道当作独立测试样本。
- 输入仅发送端128维编码特征及32维IF驱动。每通道拟合一个带偏置的线性预测器；目标是原2048bytes消息计数的检测梯度符号，正号表示删除可能有利。仅有发放且梯度非零的项参与，正负类等总权重；特征归一化只从96帧拟合，ridge固定0.001、偏置不正则化。无通道标签则预测0。5152个线性参数，非新增检测器训练。
- 学生从原消息中最多抑制32个预测有害的单位事件。随机对照删除同数量原单位事件，seed+frame_index；oracle另用留出标签做解释性参照，禁止影响学生和拟合。
- 删除对应原前缀里最后出现的事件副本，其余顺序不变。然后从修改后的完整事件流重新执行真实codec准入，允许后续事件补位，首次超2048bytes即停。所有包头/坐标/语义元数据均计费，真正解码/对齐/检测；因此修复上一轮“少脉冲但超预算”的问题，但新机制也包含补位，不能只归因为删除。
- 源端决策不读取本地车特征/GT/接收端梯度；这些仅为训练监督或留出评价。相同源/接收状态用于全部四种前向。保存拟合参数、特征/梯度、选择记录、真实包及文件SHA；冻结权重和缓冲逐值核验。两小时硬上限。

## 判定与退出

学生在32留出帧的平均实际检测损失须同时低于原IF和同数量随机抑制，至少20/32帧优于随机，且所有包不超过2048bytes，才进入下一步完整AP评估设计。此门槛是工程筛选，无统计显著性或泛化声明；loss不是AP，仍不能宣布总目标达成。

只有这一组96/32、一个线性模型，不扫宽度/正则/seed/删除数量。若不满足，结束此线性预测实现；不能泛化为所有源端信息都不可学习，也不能为了正结果立即堆网络或加标签。若满足，下一步将冻结选择器，在完整验证集评估实际通信—AP，并准备原IF/无效用监督/强ANN公平对照；不把3种训练历史不同的模型解释为单一激活的因果比较。
