## 两阶段研究目标

第一阶段基于 E-3DSNN 证明 SNN 协同融合的精度—通信量优势。
主要精度指标为 BEV AP70，AP30/AP50、3D AP 辅助汇报。
同一 cooperative GT、数据划分和训练预算下，SNN 融合 AP70 必须高于 SNN 单车和 ANN 单车；
可以略低于 ANN 融合，但必须同时给出准确的精度差与真实编码字节，不预设“略低”的数值容忍阈值。
当前全SNN在原辅助监督基础上追加10轮冻结编码器适配后，独立复核AP70=58.01125%，高于固定ANN单车57.98007%仅0.03119个百分点；本次单种子点估计越过参考线，尚未证明稳定优势或完成匹配预算/独立泛化验收。原30轮辅助监督三种子均未过线，不能混合为同一协议的重复。
低通信量本身不能替代精度门槛；后续等码率量化 ANN 对照用于验证表示优势。

第二阶段在第一阶段证据与 E-3DSNN 架构经验上，设计更适合跨视角对齐、融合和通信的 SNN 架构。
此阶段才集中发展结构创新；当前优先解决可复核的精度与通信权衡。

   核对帧顺序、逐帧 GT 数组、所有文件哈希；按仓库原 score-greedy 匹配精确复现 AP50/AP70。
   输出 IoU0.7 的保留/丢失/新增 GT、最佳 IoU 分布、误检分组与置信度阈值统计。
   已保存的是 NMS 后预测，不能据此直接确定 NMS、量化或对齐的因果责任。
3. GPU 可用后先以融合 best@27 完整权重、ego 配置关闭路端，评估并 CPU 复算。
   随后从各自冻结单车 best@53/55 初始化，分别执行 cooperative GT 下 ego 30 epochs。
   使用原 batch=2、Adam 0.0002、学习率里程碑20/27、种子20260929及相同数据增强。
   ego 无融合模块可预热，因此使用30轮全模型训练；原融合为3轮融合预热+27轮联合训练。
   这是相同总轮数且给单车充分优化的对照，不宣称两者每个参数的更新次数相同。
4. 新训练以 AP70 选 best.pth，同时独立保留 best_ap50.pth、best_ap70.pth 及对应指标。
   同分保留最早轮次，恢复训练必须保持选择规则；旧状态恢复的 AP70 追踪起点另记。
   新的最佳权重均需独立评估、归档预测及 CPU 复算。
5. 依据诊断和同预算单车结果，才决定融合激活/对齐消融；不提前归因于脉冲计数。

以下 TP/FP 和召回/精确率使用当前导出的 score>=0.2、NMS 后预测，IoU阈值0.7；不等同于 AP。

| 模型 | AP70 | TP70 | FP70 | 召回率 | 精确率 |

| SNN 固定 ego | 54.77% | 17,065 | 8,439 | 59.62% | 66.91% |
| SNN residual | 54.26% | 17,735 | 11,043 | 61.96% | 61.63% |
| ANN 固定 ego | 57.98% | 17,644 | 7,368 | 61.64% | 70.54% |
| ANN residual | 58.46% | 18,480 | 10,750 | 64.57% | 63.22% |

| IoU0.7 下 GT 匹配状态 | SNN | ANN |
| --- | ---: | ---: |
| ego 与融合均匹配 | 15,186 | 16,199 |
| ego 匹配、融合未匹配 | 1,879 | 1,445 |
| ego 未匹配、融合匹配 | 2,549 | 2,281 |
| 两者均未匹配 | 9,008 | 8,697 |
| 融合净增加匹配 | +670 | +836 |

SNN 并非总召回下降：正确匹配净增670，但错误检测增加2,604。
其中与任意GT的最大IoU处于[0.3,0.7)的错误检测从3,552增至5,507（+1,955），
最大IoU<0.3的错误检测从4,887增至5,536（+649）。
ANN 的前一类从3,092增至4,951，后一类从4,276增至5,799，正确匹配净增836。
两者都出现误检增加；不能仅凭FP总数解释AP涨跌，AP取决于整条排序后的precision-recall曲线。
SNN 对既有匹配的丢失更多：1,879 个丢失 GT 中，1,411 个在融合后仍有最大 IoU 处于 [0.5,0.7) 的预测，16 个仍有 IoU>=0.7 预测但未被贪心匹配。
ANN 对应为 1,445 个丢失 GT 中 943 个处于 [0.5,0.7)，13 个仍有 IoU>=0.7 预测。
这支持优先检查高IoU目标的退化及匹配变化，尚不能直接指定为某个网络模块造成。
不同网络的相同分数阈值不代表相同校准水平，不把阈值统计直接解释为排序的因果证据。
