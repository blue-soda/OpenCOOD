# 研究总目标与阶段退出规则（2026-10-18）

本文记录用户2026-10-18最新路线要求，是后续自动任务的优先决策入口；与旧实验计划的优先级冲突时，以本文为准。既有结果和预先实验协议保留，不改写历史结论。

## 总目标

第一阶段：基于E-3DSNN建立SNN协同感知的精度—通信量证据。主指标为BEV AP70，目标在相同数据/GT和匹配训练预算下高于ANN、SNN单车，可略低于ANN多车，同时统计真实逐帧通信字节。允许采用SNN前端/融合＋ANN BEV＋连续检测头的混合架构；全链路SNN、彻底解释或消除BEV精度差距，不再是转入通信与融合研究的硬性前提。

第二阶段：结合上述证据设计更适合协同感知的SNN消息表示、前端与融合架构，形成可验证的创新与论文叙事。以通信预算下的检测性能为中心，不将局部单模块最优替代整体目标。

## 已有证据与表述修正

固定SNN编码器的融合×BEV对照，SNN融合＋SNN BEV为57.71235%，ANN融合＋SNN BEV为58.10728%，SNN融合＋ANN BEV为60.03047%，ANN融合＋ANN BEV为60.58357%；平均通信量均约91.24722 kB/帧。说明ANN BEV后端是可行路线，不能据此声称Residual融合及之前采用SNN完全不损失精度。固定ANN BEV时仍有0.55311个百分点的融合差距。

所有版本的cls/reg/dir检测头都是普通1×1卷积，输出连续值，没有Count4输出量化。“SNN BEV＋检测头”仅指SNN BEV及其共同训练的检测头权重来源，后续表格须分开标明BEV激活、检测头算子类型和头权重来源。现有模块包交换包含权重、激活、BN和头的适配，尚未隔离BEV与检测头各自的因果贡献。

历史固定ANN/SNN单车AP70为57.98007%/54.77316%。混合60.03%是超过这两个固定参考的单种子点估计，不等于完成匹配预算、多种子或独立泛化验收。原Count4对FP32无损通信比较尚不能替代等码率量化ANN对照。

## 有限接收端研究及退出规则

1. 完成已经启动的BEV步长×学习率四组实验及最终独立复核，保持原预定对照、结果保留和验收规则；无论正负结果均归档，不因新路线重启或追加无计划搜索。
2. 允许继续检验BEV特征与连续检测头的适配：优先复用现有预测做定位/排序误差分析；确有未解问题时，最多追加一轮小规模、匹配预算的针对性对照，例如冻结BEV仅更新连续头，对比同初始化下BEV与头共同更新。先明确该对照能回答什么，避免把头权重或BN适配混作神经元因果效应。
3. 这“一轮”是当前执行预算，不是用户要求必须开展。若现有结果已足够选择实用后端，或补充对照不能改变路线决策，直接转入主线。无明确新增证据时，不继续串行扩展BEV变体、种子搜索或检测头改造；有明确收益则保留候选，也同步转入主线。
4. 不以“全SNN超过ANN单车”作为退出接收端研究的必要条件。可选择SNN前端＋SNN融合＋ANN BEV＋连续头作为主要候选，SNN前端＋ANN融合＋ANN BEV作为参照，全SNN作为对照。后端选择记录精度、代价及理由，不将混合模型写成全SNN。

## 接下来必须回归的主线

- 固定可用后端及评估协议，优化SNN前端消息表示与SNN融合；研究消息选择、计数精度、通道/空间预算及其与融合的联合适配，先做小而可解释的对照，再扩展有效方案。
- 绘制真实逐帧字节—AP70曲线，报告均值、P95与必要的编解码/推理耗时。保持数据划分、GT、对齐、后处理、模型选择和训练预算可比；补齐同预算ANN量化/压缩及ANN融合对照，区分脉冲表示与普通量化带来的收益。
- 对有希望的候选做匹配种子与泛化验证；单次越线不写成稳健优势。保留失败、负结果与复算证据。
- 同步建设论文“问题—方法—证据—边界”的叙事：稀疏脉冲消息是否在同等通信预算下保留协同检测价值；融合如何使用这些消息；相比量化ANN的独立贡献是什么。未证实的能效、机制或新颖性不得提前写成结论。
