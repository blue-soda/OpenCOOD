# 主研究路线：连续膜电位、发放后余量与可学习渐进发送的联合实现

## 用户决策与优先级（2026-10-19）

用户重新确认：昨天提出的三个部分共同构成主要研究路线。先完成当前Count3低通道四组实验的最终复核，再推进三部分的联合实现。本文件和RESEARCH_GOALS.md顶部的同名决策优先于历史记录中“下一步转向内容压缩”等临时安排。保留全部旧实验与负结果，不改写历史。

核心问题：车端以自身阈值前的连续膜电位作为真实接收状态，路端学习在不同消息批次发送哪些增量脉冲，车端在严格对齐后逐批接收、发放，并将发放后的剩余信息传给下一批，能否改善实际通信预算下的协同检测？

第一阶段目标保持不变：同一数据/GT与可比预算下，BEV AP70高于ANN/SNN单车，可略低于ANN多车，同时报告真实逐帧字节。第二阶段以这套联合机制发展适合协作的SNN架构。允许ANN BEV和连续检测头；强量化ANN始终是对照，不提前宣称脉冲独有优势或硬件节能。

## 三部分的实施判据

| 部分 | 必须实际实现 | 不能当作完成的替代物 |
|---|---|---|
| ① 连续本地膜电位 | 本地阈值前张量进入接收状态初始化和后续检测计算图；同一阈值后计数、不同阈值前余量应在受控后续输入下产生可区分的响应 | 仅捕获/暂存张量，随后融合仍只使用阈值后特征；连续旁路不参与输出 |
| ② 发放后余量保留 | 显式定义膜电位更新、发放、复位/扣除与余量；第k批余量实际进入第k+1批状态，按帧生命周期结束 | 仅累积远端浮点特征，再调用普通Residual；每批重建或清零余量；重复加入已经融合过的累计消息 |
| ③ 可学习渐进发送 | 发送端内容/脉冲生成与批次分配接受多前缀检测监督，与接收端共同优化；推理仅用发送端可获得的信息，硬消息符合真实codec | 固定q≥1/2/3拆包被称为学习排序；只训练接收端；不可微排序没有有效发送端梯度；只重排冻结的固定消息集合却称完整编码器联合训练 |

三者须在同一forward、同一组训练目标中联合工作。固定发送、清零余量、只用本地计数等允许作为明确标注的消融，不得成为未说明的主模型替代。

## 状态与对齐要求

先预登记状态的物理/数值含义：本地初始化U0、每批对齐输入Ik、发放Sk、发放后余量Rk以及对检测器的读出。可用`U_pre,k = R_(k-1) + I_k`、`R_k = U_pre,k - reset(S_k)`表达增量过程，但具体阈值、截断、泄漏、负电流/抑制、累计输出与当前输出必须在实现前定清，不能把普通ReLU或Count4取整直接改名为LIF。若采用“累计读出q＋余量r”的等价记账，须证明重构连续状态一致，避免把q重复加回造成重复积分。

保留膜电位/余量不是要求公开发送车端连续状态。路端消息仍可稀疏编码为脉冲/计数；插值与接收端状态可为连续值，不称全程整数或纯AC。

每个样本、每个发送者独立绑定源/目标帧、实际时间戳、位姿、3D网格和通道basis身份；先在3D中对齐到共同位置和通道约定，再将电流加入接收状态，HeightCompression在其后。共享编码器或显式学习的适配器须有版本与权重身份；相同维度不等于相同语义。禁止混帧、错位、不同basis直接相加；消息丢弃不表示空闲空间。先限定当前帧内单路端，不擅自扩展跨帧记忆或异构多端。

## 联合实现的最低验收证据

- 本地阈值前值不是死变量：受控扰动/梯度与状态测试证明其进入后续响应；零消息路径与已声明的本地读出一致，若改变原本地读出，单独记录并对照。
- 余量有因果作用：构造小于阈值的分批输入，保留组跨批触发、清零组不触发；同时验证抑制输入、溢出与复位规则。无泄漏线性控制中，分批和一次输入满足预期守恒关系；不把这个恒等式当作精度创新。
- 发送端确实可学习：检测损失反传到已登记的发送内容/批次分配模块，有限非零梯度与一次更新后的消息变化可见；记录替代梯度偏差，推理不读取GT或未传输的接收端信息。
- 实际包前缀重建正确，坐标/basis/帧/位姿/序号错误会拒绝；batch与逐帧、通信前后、重复forward和dropout均验证；所有新增状态不跨帧泄漏。
- 所有前缀用同一已登记best选择规则，报告AP30/50/70、真实字节均值/P95与计时；不事后各前缀选各自最佳以夸大曲线，保留强ANN和历史Residual参照。
