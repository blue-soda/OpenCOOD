## 消息支撑定义

接收端在三线性插值之前，从解码得到的128通道三维特征R构造o(z,y,x)=1[该位置任一通道非零]。用相同SE(3)、原点和网格步长得到m=warp(o)，并限制于几何覆盖c内。m为插值权重支撑，既不是占用概率，也不是自由空间或可见性；不区分被预算丢弃和本来无非零特征的位置。三层高度fold为3个mask通道，列支撑u=max_z(m)。

received组将融合输入中的c替为m，残差门控由max_z(c)替为u：delta=Fusion([ego, aligned_road, m])，fused=A(ego+alpha*u*delta)，u=0处严格返回ego。geometry组保留原公式。此轮是“支撑输入＋残差门控”的组合干预，不声称已拆分二者独立贡献。消息dropout同时将road和mask置零，因此缺包回退不变。支撑从已收到的值/坐标推导，零额外发送字节；增加一次单通道warp及接收端运算，尚不声称降低延迟或能耗。
