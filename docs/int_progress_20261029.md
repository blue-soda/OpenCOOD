## 哪些经验值得保留

**成熟读出直接放开训练没有改善整体结果。**固定同一份joint e33更新器、逐扫描确认完全相同的Z，仅交换读出：原固定读出74.5460%，适配读出74.3886%，适配下降0.1575个百分点。对完整当前Z，适配读出也使AP从75.6791%降至74.7910%。这支持当前保留成熟读出，不证明所有可训练读出设计都无效。

**恢复固定读出并重新适配更新器是本阶段最明显的精度进展。**从交换后的74.5460%升至74.9420%；这里包含额外训练，不能把全部增益都归于单次读出交换。

**逐通道门提供小幅正向信号。**空间门让同一位置96个通道共用一个历史保留比例；逐通道门允许分别调整。两组初始AP完全相同，最终best差0.0652个百分点，额外参数6175、平均计算增加0.2004G。e2–e6同轮均领先，但只有单种子，提升小，不宣称统计显著。

**扩大卷积范围和末端点式校正都没有解决主要缺口。**dilation实验恢复到平台仍低于plain，且未来局部邻域半径从2增至3。rank16点式校正无法修正空间位置偏差，只能混合通道，其失败不能否定有空间依赖的修正网络。

**诊断更支持优先检查单步重建，而不是继续延长训练。**恢复组e3的512训练扫描中，把历史换成完整教师历史，年龄2的Z误差仅减少约4.03%；年龄1仍有明显误差。该诊断不是可部署策略、AP上限或对误差来源的完整证明。

## 距离主路线目标还有多远

最佳Z方案相对HDY：AP低0.4304个百分点，计算量反而高约21.76%；持久FM/空间缓存从86.0832MB降到35.8848MB，减少约58.31%（不含临时激活、邻域表等，不等于峰值显存）。因此当前价值是缓存简化和降低状态存储，不是整体效率已胜出。没有新增的、足以证明Z相对HDY延迟胜出的同轮配对证据。

Z当前仍是小更新器整图运行，尚未实施变化区域的真实局部跳算。HDY的局部重算/未选位置复用已验证，不能把新Z探索与该成果混淆。

## 下一步建议（本次汇报未启动新实验）

1. 保留HDY为性能基线、75.0083%的逐通道Z为简化基线；不继续机械续训已达平台的门控、dilation或点式校正。
2. 先在固定训练扫描上分解Z误差的空间位置：目标/边界、已覆盖区域、新暴露区域等，检查剩余误差能否集中到较小面积。利用教师作离线局部替换诊断时明确其不可部署性，不把先算完整教师再替换的结果当作真实省算证据。
3. 若误差集中，优先设计有空间上下文的局部修正：未选位置直接保留对齐Z，只在选中区域及必要邻域计算更强的修正。选区由训练集确定，完整验证同时记录AP、实际执行面积、含邻域的FLOPs、状态/峰值显存及同卡配对延迟。
4. 若恢复精度需要大面积重算，则说明当前单Z瓶颈位置不合适，应重新审视保留更丰富的中间状态或空间编码，不继续依赖检测前的小校正层。
