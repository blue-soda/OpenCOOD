## 前一阶段已确认结构（2026-10-19，保留实验记录）

当前点云 → 继承的Pillar及第一级ResNet → E（128×100×252）。历史检测前状态H（256×100×252）位姿对齐得到H预测。便宜的选区模块在昂贵更新网络之前产生M；更新网络U只对选区及必要邻域计算。H新=(1-M)H预测+M·U(E,H预测,有效覆盖)，接继承的1×1分类/回归/方向头。整图基线令M全1。

U先用1×1将E128、H预测256和valid1投影到128通道；当前分支初始化为单位映射，历史/valid分支初始化为0。随后迁移原第二级ResNet前两个残差块，首块conv及残差投影的stride由2改为1，其余权重形状与值继承，输出256通道。四个3×3卷积的输入依赖半径4；BN固定运行统计，允许训练affine参数。持久状态就是送入检测头的高层特征，没有原GRU、后续整图多尺度解码或shrink。当前浅层编码和检测头仍每帧整图计算。

迁移不等于精度等价：步长变动、移除GRU和解码都会改变表示，原第一级曾消费GRU输出，直接接Pillar也有输入分布变化。允许小学习率调整浅层空间权重；冻结教师提供GT之外的检测和高层特征蒸馏。教师仅用于训练监督，不为学生初始化/刷新历史状态，不参与验证或推理。

## 当前阶段的多维收益判据（2026-10-21用户修订，优先于下文历史结论）

**计算面积与FLOPs/MACs减少是独立的正向研究信号，当前GPU延迟未下降不能单独否定方案。** 精度、算量和延迟并列报告，分别判断“计算量节省是否成立”“精度代价是否可接受”“当前执行器是否实现加速”。以精度—计算量—延迟的权衡保留候选，不只按毫秒排名。此前“失败/不保留为性能改进”等结论若只基于延迟，应解释为当前GPU加速未成立；确有算量降低的分支仍可作为后续设计起点。

统一记录四层量，不相互冒充：

1. 实际状态写入比例：最终替换了多少H，不能直接当卷积计算面积。
2. 实际执行输入面积：包含重复邻域、重置、整图回退及批处理副本；区别于候选/规划面积。
3. 沿实际执行路径的标准FLOPs/MACs：按算子、输入输出形状计数，约定1 MAC=2 FLOPs。注明模块范围和未计项；卷积/线性FLOPs不是完整系统所有运算，也不是GPU硬件指令数。仅在核验结构后才能用面积比例推导对应模块的FLOPs比例。
4. 理想去重稀疏依赖量或未来事件驱动运算量：单列为潜力估计，不能写成现实现已经取得的节省。GPU毫秒、P95和内存继续实测，后续能耗若未实测则不宣称下降。

当前局部状态网络E/U/头与选区MLP均为ANN，当前实验不含脉冲神经元；不能写成“未来转成ANN才有收益”。若后续改为更合适的稀疏ANN、SNN或专用执行器，较少更新区域可能更有效地转化为延迟/能耗收益，作为需要验证的假设保留。现有缓存感知训练按原协议继续，不因本判据修订改动活动任务。
