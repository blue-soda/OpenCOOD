## 与此前整级缓存的区别

原主干有3/4/5个残差块组成的三级，整级输出局部裁剪需要在其输入上扩展11/15/19格邻域。新适配器逐块缓存12份输出：带stride2的首块半径3，其余stride1块半径2。每块选中区域读取上一块的混合结果及必要邻域；未选中的输出直接保留同层对齐缓存。这样无需为一个深层选区从整级输入重复执行很大的邻域，但每块的对齐、索引、搬运和额外缓存会增加开销，不能只由半径变小宣布提速。

局部参考语义是“在上一块的混合输入上整图算当前块，再按相同mask写回”，不是原始完整INT当前帧输出。上游复用误差会传递到后续更新区域，这是必须用检测AP检查的误差来源。

选择接口在昂贵空间块之前：复用GRU的state_observer提供的当前hidden与GRU已经对齐的历史hidden，计算相对RMS差；不再为比较GRU历史额外warp一次。该启发式阈值尚未标定，不是可靠的静态/动态分类器。每个空间块的特征仍需自己的网格对齐；新增覆盖和缓存年龄到限强制更新。threshold=None强制全选，是当前精度验收路径。

整图Pillar、GRU、解码、shrink、检测头尚未跳过。没有把原INT原封不动地整图执行称为已经省算；当前进展是建立了可选执行空间路径及同权重整图参照。

## 网格位置与缓存

3×3、padding1、stride2卷积的输出第0格中心仍位于输入第0格中心。输出的间距扩大，但不能把输出网格重新按原范围均分，否则旋转warp会产生半格相位偏移。新代码根据原Pillar网格分辨率、累计stride及实际输出大小生成每个缓存的物理边界；支持奇数尺寸。此修正仅作用新逐块缓存路径，不重写历史报告，也不能据此归因过去的精度损失。

每块缓存输出与年龄，使用既有nearest SE(2)对齐，源状态不原地修改。场景切换/显式reset/超时间隔跟随原GRU重置；非因果时间拒绝。真实配置缓存总量107,282,700字节（约102.31MiB，含GRU、12块特征和年龄，不含临时张量），需要在真实GPU计时中承担相应内存代价。
