## 问题、假设与本轮调整
最终目标仍是保留检测精度，使变化区域承担主要重算，不是追求最小参数量。第一版209,396个可训练参数把原GRU、ResNet、多尺度解码全部替换，40轮最佳完整AP70仅55.96106%，当前在GPU0续训至总60轮上限。第一版的低精度同时混合了表达能力、空间上下文、优化和时序学习等变化，不能归因为“统一状态不可行”，也不应等它独占一个GPU训完才修订。

代码观察：第一版当前观测只有一个标准3×3下采样卷积、一个逐通道3×3和逐点混合；粗上下文平均池化后只有一层逐通道5×5；更新模块为逐点混合和两层逐通道3×3，状态128通道，读出逐点。没有残差空间编码或归一化。相比原约30.8M检测器，这既是大幅容量压缩，也是空间表达结构替换。参数少或结构弱目前是待验证解释，并非已经证明的唯一原因。

用户本轮明确授权及时修改并利用空闲GPU。本轮不等待v1结束，启动v2时序版及同架构单帧训练对照。v2是工程组合修订，同时改宽度、残差空间编码、上下文和逐位置通道归一化；结果改善只能支持这组修订，不可拆分为其中某一项的独立贡献。

## 第二版架构
1. 冻结原Pillar/scatter仍为64×200×504。当前观测以3×3 stride2到128×100×252，加两个残差瓶颈；瓶颈含1×1降通道、标准3×3跨空间与跨通道混合、1×1恢复。
2. 上下文以3×3 stride2到192×50×126，残差瓶颈，再stride2到256×25×63，依次使用dilation=1/2/3的三个残差瓶颈；投影128通道并双线性上采样至100×252，与当前观测拼成256通道证据。不是原多尺度转置卷积解码器。
3. 唯一时序状态扩到256×100×252，FP32为25,804,800字节。继续使用原SE(2) warp、场景/间隔重置与有效覆盖约束；不引入目标运动预测。
4. 更新模块输入当前证据256+对齐历史256+valid1，经1×1投影、两个残差瓶颈、1×1输出候选修正与保留门。每个瓶颈仅一层标准3×3，故在预计算证据上的更新依赖半径仍为2。逐位置LayerNorm只对通道归一，不混合不同空间位置，避免局部裁剪因空间统计产生不一致。
5. 状态经逐位置归一化、1×1读出和可训练检测头输出。检测头仍用同一教师头初始化，其余新核心从seed303随机初始化。不注入教师特征或状态。

首版v2依然每帧整图计算观测、上下文、状态更新及检测；尚无区域选择。局部等价仅针对**已计算好的当前证据+历史状态**上的更新模块，不意味着整个新编码器都能半径2裁剪。上下文仍是稠密成本，未来要单独评估低频缓存或选择执行。MAC只计Conv2d，不能替代实际延迟；参数、MAC、实际状态量在工程验收后记录。
